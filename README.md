# Klaku

Free, single-button games for children with special needs, designed with
cortical visual impairment (CVI) in mind.

Klaku is a launcher that holds many small games. Everything works with one
switch, a tap or a click. It runs in the browser, installs as an offline app
(PWA), and updates itself.

**Status:** WIP

## Design principles

- Black background, flat saturated colours, simple bold shapes.
- No gradients, glow, clutter or patterns.
- One clear focus at a time, with a thick ring around the active choice.
- No accounts, tracking or data about children.
- Works offline.

## Quick start

```sh
nix develop      # or: direnv allow
npm install
npm run dev
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for development details and how to add
a game.
